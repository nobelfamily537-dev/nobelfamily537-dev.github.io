AniPix Changelog: What Each Update Actually Changed

Last updated: 22 November 2026

A running record of what has changed in the AniPix app, so you can tell whether an update is worth installing. Entries are grouped by release and describe what actually changed for the person using the app, not the internal work behind it.

How versioning works here

Every build gets a new number. A build that changes only the wallpaper library keeps the same features and the same layout — the number moves because the library moved. Builds that change behaviour are called out explicitly in the entry.

Because the app is distributed directly rather than through a store, updates are not pushed to you. You install a new build when you want it, and your settings carry over.

What the recent builds changed

Live wallpaper playback

The most substantial fix in recent history. Live wallpapers that downloaded correctly were still showing as static images on some phones. The cause was that the video was being handed to the system as a remote stream rather than a local file, and the media player never received a ready callback, so it silently never started.

The fix downloads the clip to local storage first, then plays it from there. The preview now shows a poster frame while it loads, with a real progress indicator and a timeout, and error codes are surfaced instead of a silent failure.

Static-frame locking on the home screen

Some manufacturers lock a static bitmap over a live wallpaper on the home screen while leaving the lock screen animated. Earlier builds tried to work around this in a way that produced a frozen image on those devices. That approach was removed; the app now detects whether a clip is actually playable before offering it as a live wallpaper.

Download validation

Failed downloads previously left a partial file that looked like a wallpaper and behaved like a corrupt one. Downloads are now written to a temporary file, checked for a minimum size and a valid container header, and only then renamed into place. A failed download now reports as a failure.

What is deliberately not in the app

Worth stating, because people ask for these regularly:

  • No video downloading from other sites. The app is a wallpaper browser, not a media downloader.
  • No account required. There is no sign-in, no profile and no cloud sync of your choices.
  • No third-party analytics beyond crash reporting. The app does not build a profile of what you look at.

Reporting a problem

If a build misbehaves, the useful information is: your phone model, your Android version, and what you did immediately before it went wrong. Send that through the contact page. Reports that include the phone model get fixed much faster than reports that do not, because half of these problems are manufacturer-specific.

Requesting a feature

Feature requests are read. The ones that get built are usually the ones that solve a problem many people have rather than one person's preference. Requests that describe the situation — "I cannot find wallpapers for a specific show because the search only matches exact names" — are far more actionable than a one-line wish.

Keeping the library current

The wallpaper library is the part of the app that changes most often, and it changes independently of the app build. New wallpapers are added on a schedule throughout the day, across categories. If a category feels thin, it is usually because it was recently cleared of low-quality entries rather than because nothing was added.

Why there is no automatic update

Apps installed from a store are updated by the store. An app distributed as a direct APK has no such channel, so a new build only reaches you when you install it. That is a deliberate trade: it means no store review delay and no store policy deciding what the app may contain, at the cost of you having to check occasionally.

Installing a newer build over an older one keeps your settings. You do not need to uninstall first, and you do not need to re-download wallpapers you have already saved — those live in your own storage.

What is planned next

The library keeps growing, and the work that matters most right now is coverage: making sure that every popular series has wallpapers rather than a handful of series having hundreds. Search quality is the other area — matching on partial names, alternate spellings and character names rather than exact strings.
