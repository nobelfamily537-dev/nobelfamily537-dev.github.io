Live Wallpaper Not Working? Six Causes and Their Fixes

Last updated: 22 November 2026

A live wallpaper that plays in the app's preview and then sits still on the home screen is the most common complaint about animated wallpapers on Android. It is almost never a broken file. Here is what is actually going wrong, in the order you should check.

Cause 1: the system applied the preview image

Most live wallpaper apps show a static thumbnail while they load the video. When you press the system's "Set wallpaper" option instead of the app's own button, some launchers pick up that thumbnail and apply it as an ordinary image.

Fix: open the app, open the wallpaper, and use the button inside the app. Not the share sheet, not the gallery menu.

Cause 2: missing overlay permission

A live wallpaper draws behind your icons, which some Android skins treat as drawing over other apps. Without that permission the wallpaper service starts and immediately stops.

Fix: Settings → Apps → [app] → Display over other apps → allow. On Xiaomi and OPPO this step is mandatory and the prompt is easy to miss.

Cause 3: battery optimisation suspending the service

Android suspends background services it considers idle. A live wallpaper is a background service. When it gets suspended, you see the last frame, frozen.

Fix: set the app's battery setting to unrestricted, and if your phone has a "lock app in recents" feature, use it. This is the single most effective fix on Chinese Android skins.

Cause 4: the video never downloaded properly

Live wallpapers are video files, and video files fail in ways images do not. A partial download gives you a file that plays for two seconds and then freezes, or one that shows a single frame.

Check the file size. A short loop should be at least a few hundred kilobytes. If it is a few kilobytes, the download failed. Delete it and download again on a stable connection.

Cause 5: the phone locked a static wallpaper over it

Some manufacturers deliberately replace live wallpapers with a static frame on the home screen to save power, keeping the animation on the lock screen only. Samsung does this with its own live wallpapers. There is no setting that fully overrides it.

If the animation works on the lock screen but not the home screen, this is what is happening, and it is not a bug in the app.

Cause 6: the launcher does not support it

Third-party launchers sometimes do not pass the live wallpaper service through. If you recently changed launcher, switch back to the stock one and test. If it works there, the launcher is the problem.

Battery cost, honestly

A looping video on your home screen is a continuously running video decoder. It costs noticeably more than a static image — expect a real difference in screen-on time, more on high-resolution phones.

Practical mitigations: use a low-resolution loop (a 720p video stretched looks fine as a wallpaper), keep the loop short so the decoder does not seek constantly, and avoid live wallpapers on the lock screen if your phone has an always-on display, because both will be active at once.

How to test whether it is the file or the phone

Set a live wallpaper from a different app. If that one animates, the original file is the problem. If neither animates, the permission or battery setting is the problem. This takes two minutes and saves a lot of guessing.

How to check whether a clip is playable before setting it

Most gallery apps will play an MP4 on tap. If the file plays smoothly there, it is playable and the problem is the wallpaper service, not the file. If the gallery refuses it or shows a black frame, the file is the problem — either the codec is unsupported or the download is incomplete.

Comparing file size against duration is a quick sanity check. A ten-second 720p clip should be well over a megabyte. A ten-second clip that is 40 kilobytes is a broken download.

What to do if only the lock screen animates

This is a manufacturer decision, not a fault. Several skins deliberately keep the home screen static to save power and only animate the lock screen. There is no permission or setting that changes it, and installing a different launcher usually will not either. If the animation works somewhere, the app is functioning correctly.
