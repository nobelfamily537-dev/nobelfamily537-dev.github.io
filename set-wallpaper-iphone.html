How to Set a Wallpaper on iPhone Without Losing Quality

Last updated: 22 November 2026

iOS handles wallpapers differently from Android in ways that matter: there is no separate home screen wallpaper crop on older versions, there is a depth effect that changes how the clock sits, and the photo picker will happily hand you a compressed copy. Here is how it works on a current iOS release.

The current flow

Open Settings → Wallpaper → Add New Wallpaper, or long-press the lock screen and tap +. Choose Photos, pick your image, adjust the crop, then tap Add. You will be asked whether to set it as a pair (lock and home together) or customise the home screen separately.

Depth effect — the feature that ruins crops

iOS can push the clock behind your subject so the subject overlaps it. It looks excellent when it works. It also moves the image around to achieve it, which can push your subject off-centre.

If your wallpaper looks wrong after setting it, the depth effect is the first thing to turn off. There is a small toggle on the preview screen. Turning it off restores the image exactly as you cropped it.

Photo Library compresses what you give it

When you pick an image through the Photos app, iOS may hand over an optimised copy rather than the original file. If your wallpaper looks softer than the source, this is why.

The workaround is to set the wallpaper from a file stored in the Files app instead, using the same Settings route. Files are passed through without the photo library's optimisation.

Getting the crop right

An iPhone lock screen is tall and narrow. Current models are roughly 1179 by 2556 pixels, which is close to a 9:19.5 ratio. A standard 1080 by 1920 image is 9:16, so it is too wide — iOS will crop the sides or the top and bottom.

Two practical options:

  • Use an image that already has space around the subject, so any crop is safe.
  • Crop the image yourself to roughly 9:19.5 before setting it, so you control exactly what is lost.

Home screen wallpaper on iOS

Since iOS 16 the home screen can have its own wallpaper, with a blur option. The blur is worth knowing about: it makes icons far more readable over a busy image without changing the image. If your home screen looks cluttered, try the blur before changing the wallpaper.

Live Photos as wallpapers

A Live Photo can animate on the lock screen when you press and hold. It is not a looping animation like an Android live wallpaper, and it does not play on the home screen at all.

If the animation does not trigger, the Live Photo has usually been converted to a still somewhere along the way — editing it in Photos, or transferring it through a service that strips the motion data, will do that.

Why a wallpaper can revert after an update

iOS occasionally resets wallpaper pairs after a major update, particularly if the image was stored in an iCloud-optimised state and the local copy had been evicted. Keeping the original file in Files, or in an album set to download originals, prevents it.

Reducing battery cost on OLED iPhones

OLED screens use no power for black pixels. A wallpaper that is mostly black genuinely saves battery on an iPhone with an OLED panel — and on the always-on display it saves considerably more, because the screen stays on. Dark wallpapers are not just an aesthetic choice on these devices.

Wallpaper pairs and focus modes

iOS lets you tie a wallpaper pair to a Focus mode, so switching to Work or Sleep changes the lock screen along with the notifications. It is a genuinely useful feature and it is buried: you set it inside the Focus mode's settings, not in the wallpaper menu.

The catch is that each Focus mode needs its own wallpaper pair, and iOS will not let you reuse a pair you have already assigned. If a wallpaper seems to be "missing" after you set up a Focus mode, that is where it went.

Do wallpapers sync between devices

Wallpaper choices do not sync between an iPhone and an iPad, and they do not survive a restore from a backup that was taken before you set them. Keeping the original image in Files, or in an album that is set to download originals rather than optimise storage, is the only reliable way to get it back.
